# 통역사 주간 정산 이미지 생성기

Google Sheet의 정산 탭을 읽어서 통역사별 건별 정산 이미지를 자동 생성하는 첫 프로토타입입니다.

## 실행

```powershell
npm start
```

브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:4173
```

## 현재 적용된 규칙

- 기본 정산 기간은 이번 주 금요일 기준 `이전 토요일 - 이번 주 금요일`입니다.
- `기준 끝 날짜`를 바꾸면 `기준 시작 날짜`는 자동으로 6일 전으로 설정됩니다.
- 필요하면 `기준 시작 날짜`와 `기준 끝 날짜`를 각각 직접 수정할 수 있습니다.
- `통역사`가 빈칸이면 제외합니다.
- `통역사`가 `윤토투어`, `直客`이면 제외합니다.
- `시술 금액`이 빈칸이거나 0이면 제외합니다.
- `3.3%`가 `TRUE`인 건은 `정산 금액 × 3.3%`를 차감한 `总返点金额`을 표시합니다.

## 기본 시트

현재 기본 링크는 `gid=431907368` 탭으로 설정되어 있습니다.
